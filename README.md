## 项目简介

基于 STM32F407IGTx 搭建 24V PMSM 小型风机控制系统，采用 FOC + SVPWM 实现电流、速度双闭环控制。

系统启动阶段采用电流零偏校准、转子对齐以及开环起转，低速阶段使用 ABZ 增量式编码器进行有感闭环控制，中高速阶段采用 SMO + PLL 估算转子位置和转速，并实现编码器与无感控制之间的自动切换。

项目同时实现了离线电机参数辨识、CAN 通信、速度斜坡及正反转控制，并加入过流、过压、欠压、过温、堵转、缺相及驱动异常等故障保护。

---

## 主要功能

- STM32F407IGTx + PMSM + FOC + SVPWM
- 10 kHz Id/Iq 电流内环，200 Hz 速度外环
- 三相电流 ADC 同步采样
- ABZ 增量式编码器有感控制
- SMO + PLL 无感位置、速度估算
- 编码器 / SMO 有感无感自动切换
- Rs、Ls 离线参数辨识，并根据辨识参数更新电流环 PI
- 速度斜坡、正反转过零及 PI 无扰处理
- CAN 500 kbps 通信及通信超时处理
- 过流、过压、欠压、过温、堵转、缺相及驱动异常保护

## 控制流程

整体状态机：

IDLE
↓
CURRENT_OFFSET
↓
ALIGN
↓
PARAM_IDENTIFY
↓
ALIGN
↓
OPEN_LOOP
↓
ENCODER_RUN
⇅
SMO_RUN

任意运行状态检测到故障后进入 FAULT 状态并关闭 PWM。

### 1. 系统初始化

上电后依次完成：

- TIM1 三相互补 PWM、死区和 ADC 触发配置
- ADC1 / ADC2 / ADC3 三相电流采样初始化
- TIM3 ABZ 编码器初始化
- CAN1 初始化
- TIM6 周期任务初始化
- Id / Iq 电流 PI 和速度 PI 初始化
- FOC、SMO、参数辨识、保护和状态机初始化

初始化完成后进入 IDLE，等待启动命令。

### 2. 电流零偏校准

启动后首先进入 CURRENT_OFFSET 状态。

此时关闭功率桥，仅利用 TIM1 CH4 触发 ADC 同步采样。等待电机电流衰减后，对三相电流进行多次采样取平均，获得实际 ADC 零偏值，用于后续电流计算。

### 3. 转子对齐

零偏校准完成后进入 ALIGN：

- 固定电角度 θe = 0
- Id_ref = 0.3 A
- Iq_ref = 0
- 持续约 1 s

通过 d 轴电流将转子吸附到已知位置，同时记录当前编码器位置，得到编码器电角度偏置。

### 4. 离线参数辨识

一次启动流程中首次完成对齐后进入参数辨识：

- 通过多组 d 轴电流稳态数据辨识定子电阻 Rs
- 通过电压脉冲及电流暂态响应辨识定子电感 Ls
- 对多组测量结果进行平均
- 辨识完成后更新电机参数以及电流环 PI 参数

参数辨识结束后重新进行一次转子对齐，再进入正常启动流程。

### 5. 开环起转

进入 OPEN_LOOP 后：

- Id_ref = 0
- 给定固定 Iq 产生启动转矩
- 在 10 kHz 快速控制周期中逐步增加或减小给定电角度
- 使用该生成角度进行 FOC 控制

开环运行达到设定时间，同时编码器确认电机已经正常转动后，自动切换到编码器闭环。

### 6. 编码器闭环

进入 ENCODER_RUN 后：

- ABZ 编码器提供转子电角度
- Id_ref = 0
- 速度 PI 根据目标转速和实际转速计算 Iq_ref
- Id / Iq 电流 PI 计算 Vd、Vq
- 经过反 Park 变换和 SVPWM 更新三相 PWM

SMO 在编码器控制阶段仍然后台持续运行，用编码器结果对 SMO 的角度和速度估算结果进行校验。

### 7. 编码器切换至 SMO

当选择无感控制模式后，系统不会只根据转速直接切换，而是同时判断：

- 机械转速 ≥ 500 rpm
- SMO 输出有效
- 编码器与 SMO 电角度误差 ≤ 15°
- 两者转速方向一致
- 转速误差 ≤ 50 rpm
- 上述条件连续稳定 200 ms

全部满足后才切换到 SMO_RUN，由 SMO + PLL 提供 FOC 所需电角度。

切换过程中对新旧角度加入同步偏移并逐步衰减，同时对速度 PI 进行无扰处理，降低切换时的电流和转矩突变。

### 8. SMO 回退编码器

在无感运行过程中，如果出现以下情况：

- SMO 估算失效
- 转速下降到 400 rpm 以下
- 编码器与 SMO 角度偏差过大
- 两种速度估算方向不一致

系统自动退回编码器闭环。

500 rpm 切入、400 rpm 退出形成速度回差，避免在临界转速附近频繁切换。

### 9. 10 kHz FOC 快速控制

ADC 同步采样完成后进入 10 kHz 快速控制中断，主要数据流为：

三相电流采样
→ 快速故障检测
→ Clarke 变换
→ SMO 后台观测
→ Park 变换
→ Id / Iq PI
→ Vd / Vq
→ 反 Park 变换
→ SVPWM
→ 更新 TIM1 三相 PWM

其中速度环独立以 200 Hz 运行，速度 PI 的输出作为 Iq_ref，实现速度外环 + 电流内环的串级控制。

### 10. 故障保护

运行过程中对电机及驱动状态进行监测，包括：

- 过流
- 过压
- 欠压
- 过温
- 堵转
- 缺相
- 驱动异常

检测到故障后清零 Id / Iq 给定、关闭 PWM，并进入 FAULT 状态，防止故障状态下继续输出。

## 核心代码

- `Motor/FOC.c`：Clarke / Park、Id/Iq PI、反 Park、SVPWM
- `Motor/Motor_State.c`：启动流程、状态机、有感/无感切换
- `Motor/PMSM.c`：速度计算、速度 PI、速度斜坡及正反转控制
- `Motor/Encoder.c`：ABZ 编码器位置与速度计算
- `Motor/SMO.c`：滑模观测器及 PLL
- `Motor/Motor_Identify.c`：Rs / Ls 离线参数辨识
- `Motor/Motor_CAN.c`：CAN 通信
- `Motor/motor_protection.c`：故障检测及保护
- `Motor/ADC.c`：三相电流、母线电压及温度采样
- `Motor/PMSM_TIM.c`：TIM1 PWM、死区及 ADC 触发
- `User/main.c`：系统初始化及任务调度

---

## 控制周期

- PWM / ADC / 电流环 / FOC：10 kHz
- 速度环：200 Hz
- 状态机及 CAN 周期任务：约 1 kHz
- VOFA 调试数据输出：约 100 Hz
